React’da muammo ?
Oddiy JavaScript’da o‘zgaruvchi yaratamiz:
let count = 0;
Button bosilganda:
count = count + 1;
Ammo React’da bu ishlamaydi.

Nima uchun?
Chunki React o‘zgaruvchilar o‘zgarganini bilmaydi, shuning uchun UI yangilanmaydi.
Shu muammoni hal qilish uchun React state tushunchasini ishlatadi.

State nima? tarjimasi - holat, vaziyat
State — bu component ichidagi o‘zgaradigan ma'lumot
Misollar:
savatdagi mahsulotlar
like soni
input qiymati
user login holati

Masalan:
count = 0
count = 1
UI ham 1 bo‘lib yangilanadi.

useState nima?
useState — bu React hook bo‘lib, component ichida state yaratish uchun ishlatiladi.

Syntax:
const [state, setState] = useState(initialValue);
3 ta qism bor :
state ->	hozirgi qiymat
setState ->	qiymatni o‘zgartirish
initialValue ->	boshlang‘ich qiymat

Eng oddiy misol:

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>{count}</h1>

      <button onClick={() => setCount(count + 1)}>
        +1
      </button>
    </div>
  );
}

React nima qiladi:
1️⃣ state o‘zgardi
2️⃣ component qayta render bo‘ladi
3️⃣ UI yangilanadi
